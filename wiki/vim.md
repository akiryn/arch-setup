

```
[count] + operator + [count] + motion/text-object
```

|部分|作用|示例|
|---|---|---|
|`operator`|做什么|`d` 删除，`c` 修改并进入插入模式，`y` 复制|
|`motion`|用移动的起点和终点确定范围|`w` 到下个词开头，`e` 到词尾，`b` 向后到词首|
|`text-object`|直接指定要操作的文本对象|`iw` 当前词，`i" `双引号内的内容，`a"` 连双引号一起|
**Motion（移动命令）用于描述光标如何移动，Text Object（文本对象）用于描述一块具有语义的文本区域。两者都可以与 Operator（操作符）组合，但 Text Object 并不是普通的光标移动命令。**

## 行内
```
0 跳转到行首
$ 跳转到行尾
^ 跳转到第一个非空字符
g_ 跳转到行内最后一个非空字符的位置

f{字符}   → 向右找到字符，停在字符上
t{字符}   → 向右找到字符，停在字符前
F{字符}   → 向左找到字符，停在字符上
T{字符}   → 向左找到字符，停在字符后
;    重复刚才的 f/F/t/T，保持原方向
,    反方向重复

w              下一个单词开头
b              上一个单词开头
e              当前/下一个单词末尾
ge             上一个单词末尾

对应的还有快捷键W,B,E,gE，对应的是跳转到下一个或上一个WORD，注意word和WORD不同。
word：按字母、数字、下划线及标点等字符类别划分。
WORD：只按空白字符划分。

一行很长时,可以使用:set wrap设置折行,文本会在视觉上分成多行但仍属于同一行
本质上还是属于同一行，此时j，k视觉上是跨多行移动的，附上g可以实现单行移动
gj 向下
gk 向上
g0 当前行首
g$ 当前行尾

cw 修改从当前位置到这个单词末尾的内容，效果和ce一样。光标在空格上时，通常改掉到下一个单词前的空白。
ce 从光标改到e跳到的单词末尾，包含末尾那个字符。
cb 从b跳到的单词开头改到光标前，保留光标所在的字符。
cc 修改整行 Shift+s也是修改整行
C  从当前位置修改到行尾(等价于c$)

ciw 修改当前整个单词iw = inner word
caw 修改“一个单词”这个整体，通常还会包含相邻空白aw = a word
ci" 修改引号里面的内容,不要求你的光标正好位于字符串开头ci(、ci[、ci{同理
cit 修改 HTML/XML 标签内部

c可以全部替换为d

% 光标在成对出现的内容之间跳转，例如"xxx"，[dsa], 'sadf'
```

# buffer,window,tab
ctrl+w c 关闭window
ctrl+w o 关闭除当前window外的所有window

帮助文档属于特殊的 buffer，不会被 `:buffers` 命令显示出来，我们可以使用 `:buffers!` 查看。

使用 `vsplit` 命令进行左右分屏，也可以用 `split` 进行上下分屏，还可以用这两个命令接上文件名直接在新的 window 打开文件

可以使用 `:tabnew` 创建新的 tab，使用 `:tabclose` 关闭 tab，使用 `:tabs` 列出所有 tab，使用 `:tabnext` 和 `:tabprevious` 前后切换 tab。
