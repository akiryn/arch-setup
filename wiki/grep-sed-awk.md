# grep
```bash
grep -Rh 'hotkey-overlay-title=' "$NIRI_DIR" --include="*.kdl"
```

| 语法                        | 作用                |
| ------------------------- | ----------------- |
| `-R`                      | 递归搜索目录及其子目录       |
| `-h`                      | 不在输出中显示文件名        |
| `'hotkey-overlay-title='` | 要搜索的字符串           |
| `"$NIRI_DIR"`             | 要搜索的目录            |
| `--include="*.kdl"`       | 只搜索匹配 `*.kdl` 的文件 |

```bash
grep -v '^[ \t]*//'
```

**`-v`**（`--invert-match`）：**反向匹配/排除**。即只输出**不匹配**后面正则表达式的文本行。
- **`^`**：匹配**行的开头**。
    
- **`[ \t]`**：字符集合，匹配一个**空格**（ ）或一个**制表符**（Tab，用 `\t` 表示）。
    
- **`*`**：量词，匹配前面的字符（即空格或 Tab）**0 次或多次**。
    
    - `[ \t]*` 结合在一起表示：行首可以有任意数量的缩进（空格或 Tab），也可以没有。
        
- **`//`**：字面匹配两个斜杠 `//`（即注释符号）。

```bash
sed -n -E 's/^[ \t]*(.*)[ \t]+hotkey-overlay-title="([^"]+)".*/\1|\2/p'
```

| 参数   | 作用              |
| ---- | --------------- |
| `-n` | 关闭默认的逐行输出       |
| `-E` | 启用扩展正则表达式（ERE）  |
| `s`  | 执行替换操作          |
| `p`  | 替换成功时打印该行       |
| `-o` | 只输出匹配到的部分而不输出整行 |
