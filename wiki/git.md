```bash
git rev-list --count HEAD
```
统计从当前 `HEAD` 可追溯的提交总数。`rev-list` 列出提交，`--count` 只输出数量。结果是整数，代表仓库到当前提交为止的提交次数。
> `rev-list --count HEAD` 统计的是**当前 HEAD 可达的提交数**，如果仓库有多个根、或者用了浅克隆（`--depth`），数字可能不完整。

```bash
git rev-parse --short HEAD
```
取得当前 `HEAD` 的**短哈希**（默认 7 位左右，Git 会自动选取足够区分的最短长度）。例如 `a1b2c3d`。
> 短哈希长度不是固定的，Git 会根据仓库大小动态选取保证唯一的最短前缀，所以不同仓库/不同时期长度可能不同。
