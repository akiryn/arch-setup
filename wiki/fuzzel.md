
选择和执行

|动作名|功能|默认快捷键|
|---|---|---|
|`prev`|上一项，不循环|`↑`、`Ctrl+P`|
|`next`|下一项，不循环|`↓`、`Ctrl+N`|
|`prev-with-wrap`|上一项，到顶部后循环到底部|`Shift+Tab`|
|`next-with-wrap`|下一项，循环|未绑定|
|`prev-page`|上一页|`PageUp`、小键盘 PageUp|
|`next-page`|下一页|`PageDown`、小键盘 PageDown|
|`first`|第一项|`Ctrl+Home`|
|`last`|最后一项|`Ctrl+End`|
|`execute`|执行选中项|`Enter`、小键盘 Enter、`Ctrl+Y`|
|`execute-or-next`|只有一个结果时执行，否则选择下一项并循环|`Tab`|
|`execute-input`|执行输入文本|`Shift+Enter`、`Shift+小键盘 Enter`|
|`cancel`|取消并关闭|`Esc`、`Ctrl+G`、`Ctrl+C`、`Ctrl+[`|

**移动输入光标**

|动作名|功能|默认快捷键|
|---|---|---|
|`cursor-left`|左移一个字符|`←`、`Ctrl+B`|
|`cursor-right`|右移一个字符|`→`、`Ctrl+F`|
|`cursor-left-word`|左移一个单词|`Ctrl+←`、`Alt+B`|
|`cursor-right-word`|右移一个单词|`Ctrl+→`、`Alt+F`|
|`cursor-home`|移到输入开头|`Home`、`Ctrl+A`|
|`cursor-end`|移到输入结尾|`End`、`Ctrl+E`|

**删除和粘贴**

| 动作名                    | 功能        | 默认快捷键                                     |
| ---------------------- | --------- | ----------------------------------------- |
| `delete-prev`          | 删除左侧字符    | `Backspace`、`Ctrl+H`                      |
| `delete-next`          | 删除右侧字符    | `Delete`                                  |
| `delete-prev-word`     | 删除左侧单词    | `Alt+Backspace`、`Ctrl+Backspace`、`Ctrl+W` |
| `delete-next-word`     | 删除右侧单词    | `Alt+D`、`Ctrl+Delete`                     |
| `delete-line-backward` | 删除光标之前的内容 | `Ctrl+U`                                  |
| `delete-line-forward`  | 删除光标之后的内容 | `Ctrl+K`                                  |
| `delete-line`          | 清空整个输入    | `Ctrl+Shift+Backspace`                    |
| `clipboard-paste`      | 粘贴剪贴板     | `Ctrl+V`、专用粘贴键                            |
| `primary-paste`        | 粘贴主选择区内容  | `Shift+Insert`、`Shift+小键盘 Insert`         |
