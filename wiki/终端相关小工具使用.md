## fzf

通用交互式模糊搜索工具，用于查找历史命令、文件、目录，以及筛选任意文本。

| 快捷键      | 功能      | 使用场景         |
| -------- | ------- | ------------ |
| `Ctrl+R` | 搜索历史命令  | 找到以前执行过的复杂命令 |
| `Ctrl+T` | 搜索文件和目录 | 将路径插入当前命令行   |
| `Alt+C`  | 搜索并进入目录 | 快速切换工作目录     |

- 命令输一部分后可以Ctrl+T去选择，tab可以实现多选
- 命令输入一部分后添加两个星号**(星号与前方命令要用空格分隔)可以实现Ctrl+T功能
```zsh
# 再按tab会列出所有登录过的主机名
ssh ** 
# 再按tab会列出所有进程
Kill **
# 再按tab会列出当前进程中所有变量，unset用于删除变量
unset **
# 再按tab会列出所有别名
unalias **
```

> 这种带两个星号的用法还支持自定义


递归列出当前文件夹下的所有文件
```zsh
fzf
```
一些使用
```zsh
vim $(fzf)
fzf | xargs bat
fzf --preview "bat --color always {}"
fzf --preview '/usr/share/fzf/fzf-preview.sh {}'
```







## zoxide

智能目录跳转工具，会记录你访问过的目录，根据使用频率和最近访问情况快速跳转。

```zsh
# 该工具用于替换cd，兼容所有cd相关操作
z Project
# 查看zoxide对所有目录的权重排名
zoxide query -ls
# 安装了fzf情况下可以使用zi命令，interactive交互式
# ctrl+n/ctrl+p向下向上
zi
# 还有一种交互式菜单调出方式，输入如下示例关键词后按空格再按tab，这个菜单仅显示与给定前缀匹配的条目
z kitty
```

- 不区分大小写
- 支持模糊搜索
- 路径提供的关键词需按真实路径顺序
- 关键词须匹配路径的最后部分
- 按权重选择(Frecency=frequency+recency)

```zsh
# Add a new directory or increment its rank
zoxide add ~/.config/kitty
# Search for a directory in the database
# -s 显示权重，-l显示条目
zoxide query -ls
zoxide query kitty -s
# Remove a directory from the database
zoxide remove ~/.config/kitty
# Edit the database
zoxide edit

```
