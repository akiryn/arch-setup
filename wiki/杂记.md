	知道一个aur包名怎么查看到其PGKBUILD？
1. 通过 AUR 官网查看https://aur.archlinux.org/packages/包名
2. 使用yay或paru
直接在终端输出该包的 `PKGBUILD`，无需安装软件包。
```bash
yay -Gp google-chrome
```
将构建文件下载到当前目录，然后查看：
```bash
yay -G google-chrome
```
3. 使用 Git 获取
```bash
git clone https://aur.archlinux.org/google-chrome.git
```
