# pacman命令速查
```bash
# 查询本地已安装的软件包（显式安装和依赖安装）
pacman -Q
# 列出显式安装的软件包名称
pacman -Qqe
# 列出本地已安装但不属于当前同步数据库中仓库的软件包，通常包括 AUR 软件包。
pacman -Qqm
```


#  知道一个aur包名怎么查看到其PGKBUILD？
1. 通过 AUR 官网查看https://aur.archlinux.org/packages/包名
2. 使用yay或paru
直接在终端输出该包的 `PKGBUILD`，无需安装软件包。
```bash
yay -Gp google-chrome
```
将构建文件下载到当前目录，然后查看：
```bash
yay -G google-chrome
```
3. 使用 Git 获取
```bash
git clone https://aur.archlinux.org/google-chrome.git
```

# Fontconfig
**Fontconfig 是 Linux 上负责发现和匹配字体的库。** 应用告诉它想用什么字体，比如 `Adwaita Sans`，Fontconfig 会从系统和用户安装的字体中找出合适的字体文件。它还支持别名和回退规则，比如把通用名称 `sans-serif` 匹配到具体字体，或为主字体缺少的中文字符提供候选字体。

`monospace` 是一个**通用字体名**。运行 `fc-match monospace`，实际匹配到的可能是 `Noto Sans Mono`。同类通用名称还有 `sans-serif` 和 `serif`。


## fc-list
`fc-list` 是 Fontconfig 提供的命令行工具，用于列出系统中可用的字体及其属性。
```
fc-list [选项] [模式] [格式]
```

```bash
fc-list : family | sort -u
```
这里的：
```
: family
```

可以拆成两部分：

- `:`：指定字体匹配模式，这里为空，表示匹配所有字体。
- `family`：指定输出字体的 family 属性。

## fc-match
匹配字体

| 命令                                 | 用途                          |
| ---------------------------------- | --------------------------- |
| `fc-match 'Adwaita Sans'`          | 查看请求 Adwaita Sans 时，首选的实际字体 |
| `fc-match 'sans-serif:lang=zh-cn'` | 查看简体中文无衬线字体的匹配结果            |
| `fc-match -s 'Adwaita Sans'`       | 查看按匹配顺序排列的候选字体              |


## 刷新字体缓存
```bash
sudo fc-cache -fv
```

# Firefox体验优化


| 符号  | 作用          | 示例          |
| --- | ----------- | ----------- |
| `*` | 只搜索书签       | `* github`  |
| `^` | 只搜索历史记录     | `^ arch`    |
| `%` | 搜索已打开的标签页   | `% youtube` |
| `#` | 匹配网页标题      | `# linux`   |
| `$` | 匹配网页地址      | `@ github`  |
| `?` | 搜索建议/搜索引擎结果 | `$ firefox` |

# 适合Arch的Rust安装方式
以下使用pacman管理没有使用官方安装脚本
```bash
# 安装 rustup 和基础编译工具
sudo pacman -Syu --needed base-devel rustup

# 以下以普通用户执行
rustup default stable
rustup component add rustfmt clippy rust-analyzer rust-src

# 检查
rustup show
rustc --version
cargo --version

# 日常维护
sudo pacman -Syu  # 更新系统和 rustup
rustup update    # 更新 Rust 工具链
```
