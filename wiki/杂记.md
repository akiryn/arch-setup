# Fontconfig
**Fontconfig 是 Linux 上负责发现和匹配字体的库。** 应用告诉它想用什么字体，比如 `Adwaita Sans`，Fontconfig 会从系统和用户安装的字体中找出合适的字体文件。它还支持别名和回退规则，比如把通用名称 `sans-serif` 匹配到具体字体，或为主字体缺少的中文字符提供候选字体。

`monospace` 是一个**通用字体名**。运行 `fc-match monospace`，实际匹配到的可能是 `Noto Sans Mono`。同类通用名称还有 `sans-serif` 和 `serif`。


## fc-list
`fc-list` 是 Fontconfig 提供的命令行工具，用于列出系统中可用的字体及其属性。
```
fc-list [选项] [模式] [格式]
```

```bash
fc-list : family | sort -u
```
这里的：
```
: family
```

可以拆成两部分：

- `:`：指定字体匹配模式，这里为空，表示匹配所有字体。
- `family`：指定输出字体的 family 属性。

## fc-match
匹配字体

| 命令                                 | 用途                          |
| ---------------------------------- | --------------------------- |
| `fc-match 'Adwaita Sans'`          | 查看请求 Adwaita Sans 时，首选的实际字体 |
| `fc-match 'sans-serif:lang=zh-cn'` | 查看简体中文无衬线字体的匹配结果            |
| `fc-match -s 'Adwaita Sans'`       | 查看按匹配顺序排列的候选字体              |

# 函数命名方式

驼峰命名法:大驼峰 (UpperCamelCase / PascalCase): 所有单词首字母均大写
蛇形命名法:全小写蛇形 (lower_snake_case)单词间用下划线连接。
匈牙利命名法简化：即在变量名前加上类型前缀，这有助于在调试时一眼看出变量的位宽。

模块前缀命名法：由于 C 语言没有命名空间（Namespace），为了避免冲突，通常在函数和全局变量前加上模块缩写。
    宏定义： 一律大写 UPPER_SNAKE_CASE。
    底层驱动： 常用 module_function_name (全小写蛇形)。
    变量： 常用 p_u8Buffer (前缀 + 驼峰/蛇形)。
    接口函数： 常用 Module_FunctionName (模块名 + 大驼峰)。

# Callout语法
[Obsidian文档](https://obsidian.md/zh/help/callouts#%E4%BF%AE%E6%94%B9%E6%A0%87%E9%A2%98)
GitHub 不支持的是 Obsidian 的 `-` 折叠标记，另外在 **Obsidian 叫 Callout，在 GitHub 叫 Alert（警报）**

|写法|Obsidian|GitHub|
|---|---|---|
|`> [!NOTE]`|普通提示框|普通提示框|
|`> [!NOTE]-`|默认收起，点击展开|不会触发折叠|
|`<details>` + `<summary>`|可折叠|可折叠|

|类型|适合写什么|
|---|---|
|`[!note]`|普通备注、补充说明|
|`[!tip]`|技巧、快捷键、简便操作|
|`[!warning]`|容易踩坑或需要提前确认的地方|
|`[!danger]`|格式化磁盘、删除文件等高风险操作|
|`[!example]`|示例命令、配置片段|
|`[!question]` / `[!faq]`|常见问题和解答|
|`[!success]`|成功后的预期输出|
|`[!summary]`|摘要、要点回顾|
